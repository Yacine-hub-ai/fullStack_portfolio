Libellé: Application mobile

Description:

Une application mobile (ou « app ») est un logiciel applicatif conçu pour être installé et exécuté sur un appareil électronique mobile, tel qu'un smartphone ou une tablette. Téléchargeables depuis des plateformes comme l'App Store ou Google Play, elles offrent des fonctionnalités spécifiques (jeux, services, outils) adaptées à une utilisation mobile

Technologies utilisées :

  1. HTML
  2. CSS
