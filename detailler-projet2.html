Libellé: Site e-commerce

Description:

Un site e-commerce (ou site marchand) est une plateforme web permettant d'acheter et de vendre des biens ou services en ligne. Il agit comme une boutique virtuelle, ouverte 24h/24, avec un catalogue produits, un panier virtuel et un système de paiement sécurisé, facilitant les transactions à distance

Technologies utilisées :

  1. HTML
  2. CSS
  3. JavaScript
